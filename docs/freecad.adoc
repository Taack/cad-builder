= FreeCAD Kernel
:icons: font
:toc:
:toclevels: 2

xref:../README.adoc[Back to the README]

`cad-dsl-freecad` runs the DSL in https://www.freecad.org[FreeCAD] 1.0 or later: each model is a FreeCAD document,
built by a `FreeCADCmd` process the kernel starts on first use. It makes features, not plain shapes: primitives
(`Part::Box`, `Part::Cylinder`...), sketches for the contours drawn on the faces, `Part::Extrusion` for the prisms and
the holes (its taper angle for the drafts), `Part::Revolution`, `Part::Cut`, `Part::MultiFuse`, fillets, lofts, sweeps along helices, fillings for the
plates, `Draft` shape strings for the texts. Assemblies are `App::Part` of `App::Link`.

`display("x.FCStd")` saves the document, editable in FreeCAD; `display("x.step")`, `.stl`, `.brep` and `.iges` export
the shape. `display()` checks the model, and opens it in FreeCAD with `-Dcad.freecad.gui=true` (the default of the
`cad-dsl-freecad` script). FreeCADCmd renders no images, and does not keep the colors (they belong to its GUI).

With `-Dcad.freecad.split=true` (in `JAVA_OPTS`, or `CAD_DSL_FREECAD_SPLIT=true`), an assembly saved with
`display("x.FCStd")` is split into files linked to each other, in the folder `x` beside `x.FCStd`: the assembly in
`x/x.FCStd`, each sub-assembly and each part in its own file, named after it (`box.FCStd`, then `box_2.FCStd`...). A part
placed several times has one file. The links use relative paths: the folder can be moved. With `display()`, FreeCAD
opens the split assembly.

Declare the dimensions as parameters with `param(name, value)`: they go to the `Params` spreadsheet of the FCStd file,
and every number given to a feature equal to a parameter (or to its opposite) is bound to its cell: the dimensions of
the primitives, the lengths of the prisms, the radii of the circles and arcs of the sketches (as constraints), the
positions of the primitives and sketches. Change a cell in FreeCAD, and the model follows.

.pillow-block-params.groovy
[source,groovy]
----
double length = param('length', 80)
double thickness = param('thickness', 10)
double holeRadius = param('holeRadius', 4)

cd().box(length, 60, thickness).topZ().wireFrom() {
    circle(holeRadius)
}.toFace().hole(-thickness).display(args ? args[0] : null)
----

[source,bash]
----
./gradlew :cad-dsl-freecad:installDist
cad-dsl-freecad/build/install/cad-dsl-freecad/bin/cad-dsl-freecad pillow-block-params.groovy block.FCStd
----

NOTE: The binding goes by value: give the parameters distinct values, different from the other numbers of the model.
A parameter can also be set from outside the script: `-Dcad.param.thickness=12` (in `JAVA_OPTS`), with any kernel.

`FreeCADCmd` is found on the `PATH`, or set with the `freecad.cmd` system property (or `FREECAD_CMD`); the GUI is
`FreeCAD`, or the `freecad.gui` system property (or `FREECAD_GUI`).

Both kernels build the same solids from the shared tests, within 1% for the conical helices and the lofts (B-spline
approximations). FreeCAD is slower on large models: it recomputes the document at `display()`, and checks each boolean.

[[step-to-dsl]]
== STEP to DSL

`step2dsl` (`cad-dsl-step`) converts a STEP file to a DSL script rebuilding it. It reads the STEP file in FreeCAD, and
keeps its assembly tree: a part per distinct solid, a sub-assembly per distinct sub-assembly, placed as in the STEP file.
Each solid is recognized, from the simplest to the most general form:

* a primitive: a box along the axes, a cylinder, a sphere;
* a 2.5D solid, whose faces are all normal or parallel to an axis: prisms of its cross-sections;
* a solid of revolution: the revolution of its section by a half-plane through the axis;
* else a 2.5D base, the faces that do not fit removed (defeaturing), then the holes, pockets and bosses on it (the
  material removed from the base and added to it), each one a 2.5D solid, a primitive or a revolution.

Lines and arcs of circle are kept, the other curves become polylines; what is approximated is listed in the header of
the script. Free-form parts (molded, with drafts and B-spline faces) are approximated by stacks of prisms: their scripts
are long, slow to build, and FreeCAD may reject their booleans (its `CheckModel` preference).

[source,bash]
----
./gradlew :cad-dsl-step:installDist
cad-dsl-step/build/install/step2dsl/bin/step2dsl part.step part.groovy --check   # <1>
cad-dsl-freecad/build/install/cad-dsl-freecad/bin/cad-dsl-freecad part.groovy part.FCStd
----

<1> `--check` runs the script with the FreeCAD kernel, and prints how far what it builds is from the STEP file
(the volume of their symmetric difference); without a script file, the script goes to the standard output.
